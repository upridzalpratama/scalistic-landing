# Scalistic Landing Page

Single-page landing untuk **Scalistic by Research Synergy Foundation** — platform distribusi survei & penyedia responden terverifikasi.

## Preview lokal

Cukup buka file `index.html` di browser (double-click), atau jalankan:

```bash
python3 -m http.server 8080
```

lalu buka `http://localhost:8080`.

## Deploy

File `index.html` sudah self-contained (CSS/JS inline, cuma dependency Google Fonts).
Bisa langsung di-paste ke editor HTML custom di **Scalev** atau **Mayar**, atau di-host di GitHub Pages / Netlify / Vercel.

## Struktur halaman

- Hero — headline, stats, world map illustration
- Apa itu Scalistic + 5 Langkah proses
- Dual CTA (Client / Respondent)
- Section Untuk Client + pricing
- Section Untuk Respondent + mekanisme poin + benefit
- Manfaat / Why different
- FAQ
- Final CTA + Footer
